# NPS 工程図エディタ（NPS_pfcs）

工程図（Process Flow Chart）と部品別工程別能力表（Standardized Production Capacity Sheet）を、
ブラウザだけで作成・分析できるシングルページアプリケーションです。
ビルド不要・サーバー不要のプレーンな HTML / CSS / JavaScript で構成されており、
`index.html` を開くだけで動作します。

## できること

- **チャート**：工程記号（内製/外製・加工・検査・運搬・停滞）をドラッグ＆ドロップで配置し、
  線でつないで工程図を作成します。加工・検査記号にはメインライン基準で自動的に通し番号が振られます。
- **リスト**：工程を一覧形式で管理し、グループ分け・並べ替え・背骨グループ（メインライン）の指定ができます。
- **工程経路図**：複数の工程図を横断して、背骨グループ（またはグループ単位）の工程を比較表示します。
- **部品別工程別能力表**：工程ごとの加工時間・刃具交換時間・加工能力（個/日）・作業時間（手作業/自動送り）を
  一覧化し、必要数に対する能力の過不足をひと目で確認できます。
- **改善前 / 改善後モード**：同じ工程図に対して「改善前」「改善後」の2つのデータセットを切り替えながら比較できます。
- **保存・読込**：ブラウザの IndexedDB に自動保存されるほか、JSON ファイルへの保存・読込、
  印刷、PNG 画像出力（A4）にも対応しています。
- **オフライン動作**：フォント・アイコンはすべて同梱しているため、外部ネットワークに
  接続できない環境でも表示が崩れません。

## 使い方

ビルドツールや依存パッケージのインストールは不要です。以下のいずれかの方法で開いてください。

### そのまま開く
`index.html` をブラウザで直接開くだけで動作します。

### ローカルサーバーで開く（推奨）
一部のブラウザではファイルを直接開くと保存機能（IndexedDB）が制限される場合があるため、
簡易サーバー経由での起動を推奨します。

```bash
npm start          # http://localhost:8931/ で起動
```

`python3 -m http.server 8931` など、他の静的サーバーでも構いません。

## 基本操作

| 操作 | 内容 |
|---|---|
| 記号の配置 | 左パレットから記号をキャンバスへドラッグ、またはクリックして配置モードに入る |
| 記号の接続 | 記号の端子（ポート）同士をドラッグして線を接続 |
| フロー線への挿入 | 記号を既存の線の上にドロップすると、その位置に挿入される |
| 整列・チェック | ヘッダーの「整列・チェック」で記号間隔を揃え、ルール違反を検出 |
| 通し番号表示 | ツールバーの「表示」メニューで加工・検査記号への連番表示を切替 |
| 自動配置の変更 | 「整列・チェック」右の `▾` で枝葉グループの配置パターン（バランス/上優先/下優先など）を選択 |
| 記号の追加先指定 | リストでグループの見出しをクリックすると、そのグループが記号の追加先になる（空グループも指定可） |
| 元に戻す/やり直す | `Ctrl+Z` / `Ctrl+Y`、またはヘッダーの「戻る」「進む」ボタン |
| 保存/読込 | ヘッダーの「保存」でJSON書き出し、「読込」でJSON読み込み |

## ディレクトリ構成

```
index.html      画面構造（HTML）
css/style.css   スタイル定義
vendor/         同梱フォント・アイコン（外部CDNに依存しないため）
tools/          開発用スクリプト（簡易サーバー・アイコンサブセット生成）
tests/          自動テスト（npm test で実行）
js/storage.js   IndexedDB への保存・読み出し
js/core.js      定数・状態管理（記号定義・グループ・能力計算などの基礎ロジック）
js/graph.js     グラフ構造の計算（経路探索・通し番号の算出・線のルーティング）
js/render.js    SVGへの描画処理
js/ui.js        画面部品の生成・各ビュー（リスト/工程経路図/能力表など）の更新
js/main.js      イベント処理（ドラッグ&ドロップ・初期化・状態遷移）
```

スクリプトは `storage.js → core.js → graph.js → render.js → ui.js → main.js` の順に読み込まれます。

## 開発

```bash
npm install        # テスト実行に必要な playwright-core を入れる
npm start          # 動作確認用サーバーを起動
npm test           # 全テストを実行（テスト用サーバーは自動で起動する）
npm test layout    # 名前で絞り込んで実行
```

テストは `tests/*.test.js`。レイアウト規則・Undo/Redo・保存/復元・追加先グループ・
オフライン動作を検証します。Chromium の場所は環境変数 `PLAYWRIGHT_CHROMIUM` で指定できます。

アイコンを追加・変更したときは、同梱しているサブセットを作り直してください。

```bash
npm pack @fortawesome/fontawesome-free@6.5.1 && tar xzf fortawesome-fontawesome-free-6.5.1.tgz
npm run build:icons -- ./package
```

## データについて

- 作業データはブラウザの IndexedDB に自動保存されます（別ブラウザ・別端末とは共有されません）。
  以前のバージョンで localStorage に保存されたデータは、初回起動時に自動で引き継がれます。
- 複数の工程図をまたいで作業する場合や、他端末・他者との共有には JSON ファイルの保存/読込を利用してください。
